# VPS Deployment Guide — قانون‌یاب (modavanat.ir)

This guide walks through deploying the Next.js app to a fresh Ubuntu
VPS, including PostgreSQL install, SSL setup, and the
Prisma-free / VPS-compatible stack we built.

## 0. Prerequisites

- Fresh Ubuntu 22.04 / 24.04 VPS with root access
- DNS A/AAAA records pointing `modavanat.ir` and `www.modavanat.ir` at
  the VPS IP (do this BEFORE requesting SSL certs)
- Outbound internet access (for npm + apt + Let's Encrypt)

## 1. System packages

```bash
sudo apt update
sudo apt install -y \
  nginx \
  certbot python3-certbot-nginx \
  postgresql postgresql-contrib \
  git curl ca-certificates

# Install Bun (Node.js runtime we use)
curl -fsSL https://bun.sh/install | bash
source ~/.bashrc
```

## 2. PostgreSQL setup

```bash
# Create the DB + user
sudo -u postgres psql <<'SQL'
CREATE USER modavanat WITH ENCRYPTED PASSWORD 'CHANGE_ME_STRONG';
CREATE DATABASE modavanat OWNER modavanat ENCODING 'UTF8';
GRANT ALL PRIVILEGES ON DATABASE modavanat TO modavanat;
SQL

# Allow local TCP connections (edit pg_hba.conf as needed; default
# Ubuntu config uses peer auth for socket + md5 for TCP).
```

## 3. Get the code

```bash
sudo mkdir -p /var/www/modavanat
sudo chown -R $USER:$USER /var/www/modavanat
cd /var/www/modavanat
git clone https://github.com/Massie382/Modavanat.git .
bun install --production
```

## 4. Environment

Copy `.env.example` (or just create `.env` locally):

```bash
cp .env .env.production
nano .env.production
```

Set the values:

```bash
# Real PostgreSQL DSN (NOT pglite)
DATABASE_URL=postgres://modavanat:CHANGE_ME_STRONG@127.0.0.1:5432/modavanat

# Generate with: openssl rand -base64 32
AUTH_SECRET=<RUN_OPENSSL_ABOVE>

# Public HTTPS URL
NEXTAUTH_URL=https://modavanat.ir

# Local SMTP (Postfix / Exim) — install in step 6
SMTP_URL=smtp://127.0.0.1:25
SMTP_FROM=noreply@modavanat.ir
```

## 5. Build + run

```bash
# Apply DB migrations (creates all 12 tables)
NODE_ENV=production bun run scripts/db-migrate.ts

# Build the Next.js standalone bundle
bun run build

# Start the standalone server (listens on 127.0.0.1:3000)
bun run start
```

Make this a systemd service so it auto-restarts:

```bash
sudo tee /etc/systemd/system/modavanat.service >/dev/null <<'UNIT'
[Unit]
Description=modavanat.ir Next.js server
After=network.target postgresql.service

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/var/www/modavanat
EnvironmentFile=/var/www/modavanat/.env.production
ExecStart=/home/ubuntu/.bun/bin/bun .next/standalone/server.js
Restart=on-failure
RestartSec=3

[Install]
WantedBy=multi-user.target
UNIT

sudo systemctl daemon-reload
sudo systemctl enable --now modavanat
```

## 6. SSL + nginx

```bash
# Install the nginx site config
sudo cp deploy/nginx/modavanat.ir.conf /etc/nginx/sites-available/
sudo ln -s /etc/nginx/sites-available/modavanat.ir.conf /etc/nginx/sites-enabled/

# Get SSL certs from Let's Encrypt (interactive — pick modavanat.ir
# and www.modavanat.ir when prompted)
sudo certbot --nginx -d modavanat.ir -d www.modavanat.ir \
  --agree-tos -m admin@modavanat.ir --redirect

sudo nginx -t
sudo systemctl reload nginx
```

Cert files will be at:

- `/etc/letsencrypt/live/modavanat.ir/fullchain.pem` (cert)
- `/etc/letsencrypt/live/modavanat.ir/privkey.pem` (key)
- `/etc/letsencrypt/live/modavanat.ir/chain.pem` (intermediates)

Auto-renewal is set up by certbot's systemd timer; verify with
`sudo systemctl list-timers | grep certbot`.

## 7. Local SMTP (for email magic link)

Postfix or Exim — pick one:

```bash
# Postfix — simplest
sudo apt install -y postfix
# Choose "Internet Site" → set system mail name = modavanat.ir
```

Test it:

```bash
echo "test body" | mail -s "test subject" your@personal.email
```

`SMTP_URL=smtp://127.0.0.1:25` is what NextAuth will use.

## 8. Import laws

Drop your law JSONs into `/var/www/modavanat/laws-import/`:

```bash
cd /var/www/modavanat
bun run scripts/import-laws.ts laws-import/
```

Cross-law references resolve automatically (the importer does a two-
pass scan).

## 9. Update procedure

```bash
cd /var/www/modavanat
git pull
bun install --production
bun run build
bun run scripts/db-migrate.ts   # if migrations changed
sudo systemctl restart modavanat
```

## Notes

- `.next/standalone/` (the build output) is gitignored — never
  commit it. It's ~1GB and is regenerated by `bun run build`.
- `db/*.pglite` and `db/custom.db/` are dev-only artifacts, also
  gitignored.
- Law import JSONs (`laws-import/*.json`) are user content, also
  gitignored — drop them via SSH/SCP rather than committing.
